# فروشگاه اکانت IBSng

**ATD IBSng Store** سامانه‌ای برای ارائه و تمدید سرویس‌های اینترنتی مبتنی بر IBSng است. کاربران می‌توانند سرویس موردنظر خود را از فروشگاه انتخاب کنند، سفارش ثبت کنند و اطلاعات حساب و وضعیت سرویس خود را مشاهده کنند.

## امکانات

- مشاهده سرویس‌ها و انتخاب پلن مناسب
- خرید و تمدید سرویس بدون نیاز به ثبت‌نام یا ورود مشتری
- دریافت نام کاربری و رمز عبور سرویس؛ در صورت نیاز امکان تولید خودکار اطلاعات حساب
- مشاهده اطلاعات سرویس، وضعیت حساب، تاریخ انقضا و میزان مصرف یا حجم باقی‌مانده، در صورت ارائه این اطلاعات توسط سرویس‌دهنده
- پشتیبانی از اتصال به سرورهای IBSng
- تجربه کاربری واکنش‌گرا برای موبایل، تبلت و رایانه
- پنل مدیریت برای تنظیم فروشگاه، سرورها و سرویس‌ها

## منابع معماری و رابط کاربری

- **Routebox Telegram Bot** مرجع قابلیت‌ها و رفتار مدیریتی IBSng است؛ قابلیت سالم **Test Connection** باید حفظ شود.
- **MirzaBot (GitHub)** مرجع تکمیلی قابلیت‌های مدیریتی موردنظر پروژه است؛ فقط قابلیت‌های مرتبط با مدیریت IBSng بررسی می‌شوند.
- **ATD Files Portal** مرجع بصری رابط کاربری و سبک نمایش است.
- سورس اصلی IBSng در مبنای پیاده‌سازی این فروشگاه قرار نمی‌گیرد.
- این منابع برای استخراج رفتار و نیازمندی‌اند؛ کپی مستقیم پروژه‌ها یا اعلام قابلیت به‌عنوان آماده، بدون پیاده‌سازی و آزمون واقعی مجاز نیست.
- جزئیات تصمیم‌ها و مرزهای معماری در [PROJECT-CONTEXT.md](PROJECT-CONTEXT.md) ثبت می‌شوند.

## نصب

سامانه دارای نصب‌کننده آنلاین است و برای نصب روی هاست‌های دارای **cPanel** طراحی می‌شود. نصب‌کننده مراحل راه‌اندازی را به‌صورت گام‌به‌گام نمایش می‌دهد؛ از جمله:

1. بررسی پیش‌نیازهای میزبانی
2. وارد کردن عنوان سایت و تنظیمات قابل‌ویرایش اولیه
3. وارد کردن اطلاعات پایگاه داده
4. آزمایش اتصال به پایگاه داده پیش از ادامه نصب
5. تکمیل نصب و آماده‌سازی سامانه

جزئیات نهایی پیش‌نیازها و مراحل نصب پس از آماده‌شدن نسخه قابل نصب در همین مستند درج خواهد شد.

## مدیریت فروشگاه

مدیر فروشگاه می‌تواند تنظیمات سایت، سرویس‌ها و اتصال‌های IBSng را از پنل مدیریت کنترل کند. مبنای قابلیت‌های مدیریتی IBSng، Routebox است و قابلیت‌های تکمیلی مرتبط از MirzaBot بررسی می‌شوند. ظاهر پنل با مرجع بصری ATD Files Portal هماهنگ خواهد شد؛ UI از منطق برنامه و اتصال IBSng جدا می‌ماند.

## وضعیت پروژه

این پروژه در حال توسعه است. پایه ورود مدیر، داشبورد و مدیریت اولیه سرور IBSng (با تست واقعی Web Panel و ذخیره رمزنگاری‌شده) در مخزن پیاده‌سازی شده‌اند؛ اما هنوز روی هاست cPanel و IBSng واقعی end-to-end آزمون نشده‌اند. خرید، پرداخت، provisioning و مدیریت کامل حساب‌های IBSng آماده استفاده اعلام نمی‌شوند.
