# فروشگاه اکانت IBSng

**ATD IBSng Store** فروشگاهی برای خرید و تمدید حساب‌های مبتنی بر IBSng است. خرید مشتری به ثبت‌نام یا ورود به حساب فروشگاه نیاز ندارد.

## امکانات و محدوده

- مشاهده محصولات و پلن‌های تعریف‌شده
- خرید و تمدید سرویس بدون عضویت اجباری
- مدیریت فروشگاه، محصولات، سرورها و نگاشت دستی گروه‌های IBSng از پنل
- نمایش اطلاعات حساب و تاریخ انقضا بر پایه داده معتبر
- رابط واکنش‌گرا برای موبایل، تبلت و دسکتاپ
- طراحی دو‌زبانه فارسی/انگلیسی برای تجربه نصب و رابط‌های مربوطه در محدوده پیاده‌سازی
- نصب آنلاین مناسب هاست cPanel

## منابع و مرز پروژه

- RouteBox برای بررسی رفتار و الگوی مدیریتی IBSng و ATD Files Portal برای مرجع بصری استفاده می‌شوند.
- پروژه‌های مرجع فقط‌خواندنی هستند؛ توسعه و مستندسازی این فروشگاه فقط در مخزن ATD IBSng Store انجام می‌شود.
- این منابع مجوز کپی مستقیم یا ادعای آماده‌بودن قابلیت بدون پیاده‌سازی و آزمون نیستند.
- این Store شامل منطق ربات تلگرام یا MirzaBot نیست.
- تصمیم‌ها، وضعیت و traceability در [PROJECT-CONTEXT.md](PROJECT-CONTEXT.md) ثبت می‌شوند.

## نصب و راه‌اندازی

نصب‌کننده هدف، یک جریان مرحله‌ای ساده، امن و مدرن برای cPanel است. نیازمندی نهایی آن شامل انتخاب فارسی/انگلیسی با RTL/LTR درست، بررسی پیش‌نیازها، تنظیمات ضروری با مقدار پیش‌فرض قابل تغییر، تست اتصال دیتابیس، ثبت مدیر و ایمیل بازیابی، نصب schema و قفل نصب است.

برای نصب و اجرای migrationهای بسته ارتقا، کاربر دیتابیس باید مجوزهای موردنیاز روی **دیتابیس اختصاصی Store** داشته باشد. دسترسی سراسری به همه دیتابیس‌های هاست لازم نیست و توصیه نمی‌شود.

به‌روزرسانی از طریق بسته نسخه‌دار و با بارگذاری و تأیید دستی مدیر انجام خواهد شد؛ به‌روزرسانی خودکار از GitHub در محدوده نیست. نصب‌کننده و بسته ارتقا تا زمان اجرای آزمون واقعی cPanel آماده استفاده نهایی اعلام نمی‌شوند.

## بازیابی رمز مدیر

نیازمندی نهایی این است که ایمیل مدیر هنگام نصب ثبت شود و فرم ورود پنل گزینه فراموشی رمز داشته باشد. لینک بازیابی باید امن، یک‌بارمصرف و زمان‌دار باشد و از provider ایمیل پیکربندی‌شده استفاده کند. وضعیت پیاده‌سازی را در PROJECT-CONTEXT دنبال کنید.

## وضعیت پروژه

پروژه در حال توسعه است. پایه ورود ادمین، داشبورد، مدیریت سرور IBSng با تست Web Panel و ذخیره رمزنگاری‌شده، و نگاشت دستی Plan/Group در مخزن وجود دارند؛ اما آزمون end-to-end روی cPanel و IBSng واقعی انجام نشده است. پرداخت، provisioning، بازیابی رمز ایمیلی، نصب‌کننده دو‌زبانه نهایی و بسته ارتقا را تا زمان پیاده‌سازی و آزمون، آماده استفاده نهایی در نظر نگیرید.
